# Web animation with GSAP

A short guide to animating the web with GSAP: tweens, easing, and scroll-linked motion.

## What you will learn

- Move and fade elements with `gsap.to()` and `gsap.from()`
- Make motion feel natural with easing and stagger
- Tie an animation to the scrollbar with ScrollTrigger

## Before you start

- Basic HTML, CSS and JavaScript
- A project where you can install an npm package

```bash
npm install gsap
```

## How to use this guide

Read the topics in order. Each one is a single page with a small example you can paste into your own project.
